//! Tables
--> HTML tables are used to display data in the form of rows and columns.
--> To create a table, we use the <table> tag.

//! Table Tags
<table>
--> Represents the entire table.

<tr>
--> Represents a table row.

<td>
--> Represents table data (table cell).

<th>
--> Represents a table heading.
--> By default, the content is bold and center-aligned.

<thead>
--> Groups all the header rows of the table.

<tbody>
--> Contains the main data of the table.

<tfoot>
--> Groups all the footer rows of the table.

<caption>
--> Provides a title for the table.

<center>
--> Used to align the content at the center.

//!Note:
--> The <center> tag is deprecated in HTML5.
--> Use CSS (text-align:center) instead.

------------------------------------------------------------

//! Important Note
--> <thead>, <tbody>, and <tfoot> are optional.
--> Even if <tbody> is not written, the browser automatically creates it.
--> You can verify this using Inspect Element.

------------------------------------------------------------

//! Table Attributes

//* 1. border
--> Displays a border around the table.

Example:
<table border="1">

Note:
--> The border attribute is deprecated in HTML5.
--> Use CSS instead.

Example:
table{
    border:1px solid black;
}

------------------------------------------------------------

//* 2. cellspacing
--> Specifies the space between adjacent table cells.

Example:
<table cellspacing="5">

Note:
--> The cellspacing attribute is deprecated in HTML5.
--> Use CSS border-spacing instead.

------------------------------------------------------------

//* 3. cellpadding
--> Specifies the space between the cell content and its border.

Example:
<table cellpadding="10">

Note:
--> The cellpadding attribute is deprecated in HTML5.
--> Use CSS padding instead.

------------------------------------------------------------

//* 4. rowspan
--> Used to merge two or more rows.

Example:
<td rowspan="2">HTML</td>

------------------------------------------------------------

//* 5. colspan
--> Used to merge two or more columns.

Example:
<td colspan="3">Frontend</td>

Note:
--> rowspan and colspan can be used only with <td> and <th> tags.

------------------------------------------------------------

//* 6. align
--> Used to align the content horizontally.

Values:
left
center
right

Note:
--> The align attribute is deprecated in HTML5.
--> Use CSS text-align instead.

------------------------------------------------------------

//! Example
<table border="1" cellspacing="0" cellpadding="5">
    <caption>Number Table</caption>
    <tr>
        <td colspan="4">
            <center>1</center>
        </td>
    </tr>
    <tr>
        <td rowspan="2" align="center">2</td>
        <td rowspan="3">3</td>
        <td>4</td>
        <td>5</td>
    </tr>
    <tr>
        <td colspan="2">6</td>
    </tr>

    <tr>
        <td>7</td>
        <td>8</td>
        <td>9</td>
    </tr>

</table>
